# Audio Asset Catalog

Research only. **No audio has been downloaded or added to the project.** Every entry needs owner approval before download.

Licence rule for this project: prefer **CC0**. **CC-BY** is acceptable if attribution can be kept in a credits file. Reject NC, personal-use-only and unclear licences. Each file's licence must be checked on its own page, not assumed from the site.

Status key: **Verified** = the source page was read and the licence was seen. **Unverified** = found in search results only; the page could not be read (often HTTP 403), so the details are not confirmed.
